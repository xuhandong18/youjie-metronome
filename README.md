# 有节动作节拍器 · Capacitor 安卓版

粉色界面、离线中文语音、动作倒数、次数设置、先上后下或先下后上，以及每 N 次动作后的可选换气时间。

## 安装使用

安装提供的 `有节动作节拍器-1.0.2.apk`，点击桌面图标打开。这个安装包是签名测试版，可直接安装使用，也可以覆盖升级旧版。

手机默认完整显示操控页，点右上角“设置”打开独立面板。平板使用左右分栏，只有设置栏内部可以滚动，操控区始终保持在当前屏幕内。圆环会按剩余空间自动缩放；手机横屏和较矮窗口会重新排列控件，极小窗口保留清晰的动作文字与计时。

安卓返回键在设置面板打开时优先关闭面板。旋转屏幕或调整窗口大小不会重置当前训练。

安卓应用打开并在前台时自动保持亮屏，包含等待、设置、暂停及完成页面；离开应用或退出后恢复系统息屏规则，仍可手动锁屏。浏览器版保留“训练时保持亮屏”开关。

“启用换气”关闭时，连续进行动作，不播报换气也不插入等待。换气时长和每几次换气的数值会保留，重新开启即可恢复；最后一次结束不换气。

暂停后点“继续这一组”，先倒数“三、二、一”，再重做未完成的那一次；已完成次数保留。例如完成7次、第8次中途暂停，继续后从第8次的第一个动作开始。换气间隔仍按整组累计次数计算。首次开始前是否准备由开关决定，暂停后继续始终准备3秒。

切到后台或手动锁屏会暂停训练，回到应用后保持亮屏，但需手动继续。应用不在后台持续播报。

顶部按钮和设置面板按系统安全区域避开状态栏、摄像头缺口和底部手势区域。安卓专注模式保留系统状态栏，设置和退出专注始终可点击。

中文“上、下、换气、完成”和数字语音都在应用内，不需要网络或另装中文语音。

## 修改和构建

依赖：Node.js 22 及以上、JDK 21、Android SDK 36，以及构建工具。可以通过 Android Studio 配置这些环境。

1. 执行 `npm ci` 安装锁定的依赖。
2. 将 `JAVA_HOME` 指向 JDK 21，将 `ANDROID_HOME` 指向 Android SDK。也可在 `android/local.properties` 中配置 `sdk.dir`。
3. 执行 `npm test` 验证节拍、语音调度、暂停重做、换气开关、旧设置迁移与常亮状态。
4. 执行 `npm run build:android`。安装包按 `package.json` 的版本号输出到 `dist/`，当前为 `有节动作节拍器-1.0.2.apk`。

网页与节拍逻辑在 `web/index.html`；屏幕布局在 `web/app.css`、`web/app-layout.js`；安卓原生亮屏与设置面板返回键控制在 `android/app/src/main/java/com/youjie/metronome/`。

`npm run sync` 会将离线网页和 Capacitor 运行库同步到安卓工程。更新页面后重新构建 APK 即可。

正式分发版应配置自己的发布签名，并保留签名密钥，以便后续升级。
